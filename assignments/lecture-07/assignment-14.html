Assignment — Valid Date Checker

MediumAbout 20 minJava

The problem

You are given a year, a month and a day as three integers.

Write a program to check whether they form a real calendar date. If they do, print the date. If they don’t, print Invalid date.

LocalDate.of()DateTimeExceptiontry / catch

Input

A single line containing three space-separated integers: the year, the month and the day.

Output

If the date exists, a single line with the date object (yyyy-MM-dd). Otherwise a single line: Invalid date.

  • Think of the 31st of a 30-day month, 29 February in a non-leap year, month 13, or day 0 as invalid.

Explanation

LocalDate.of(year, month, day) refuses to create a date that doesn’t exist: it throws a DateTimeException. Put the call inside a try block and print the date when it works. In the catch block for DateTimeException, print Invalid date. (This is the same exception idea from the Errors and Exceptions chapter.)

Sample cases

Sample 1

Sample Input
2022 2 31
Sample Output
Invalid date

Explanation: February never has 31 days, so LocalDate.of(2022, 2, 31) throws DateTimeException and the program prints Invalid date.

Sample 2

Sample Input
2024 2 29
Sample Output
2024-02-29

Explanation: 2024 is a leap year, so 29 February exists. The program prints the date: 2024-02-29.

Sample 3

Sample Input
2023 13 5
Sample Output
Invalid date

Explanation: There is no month 13, so the date can’t be created and the program prints Invalid date.

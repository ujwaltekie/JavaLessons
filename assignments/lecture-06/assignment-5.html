01

The scenario

This is the capstone. You are writing the start-up routine of a report-card processor. It counts down (waiting is risky: Thread.sleep can be interrupted), tries to open a marks file (which might be missing), then goes through a batch of marks typed in by humans (who make mistakes). One program, every idea from the chapter.

Your task

  1. countdown(n): print n... down to 1... using Thread.sleep(100) between lines, then Go!. Do not use try/catch inside it. Declare the checked exception with throws instead.
  2. openFile(name): create new FileInputStream(name), then print Opened .... Declare throws FileNotFoundException.
  3. parseMark(text): use Integer.parseInt. If the number is outside 0–100, throw an IllegalArgumentException saying Out of range: plus the number.
  4. main: call countdown(3) (let main declare throws InterruptedException), then call openFile("marks.txt") inside a try/catch that prints marks.txt not found, using sample data.
  5. Process the records {"85", "abc", "130", "42"} in a loop. Each record gets its own try, with separate catch blocks for NumberFormatException (print not a number) and IllegalArgumentException (print its message), and a finally that prints Processed record N. Keep a running total of the valid marks and print it at the end.

04

Stuck?

throws goes on the method header and passes the problem to the caller. Whoever calls countdown must then catch it, or also declare it. Since main is the last stop, we declare it there as well.

NumberFormatException is a kind of IllegalArgumentException, so the more specific one (NumberFormatException) has to come first.

Declare int total = 0; before the loop and add to it only after parseMark succeeds, so that bad records never get added.

05

Solution

Main.java
import java.io.FileInputStream;
import java.io.FileNotFoundException;

class Main {
    static void countdown(int n) throws InterruptedException {
        for (int i = n; i >= 1; i--) {
            System.out.println(i + "...");
            Thread.sleep(100);
        }
        System.out.println("Go!");
    }

    static void openFile(String name) throws FileNotFoundException {
        new FileInputStream(name);
        System.out.println("Opened " + name);
    }

    static int parseMark(String text) {
        int mark = Integer.parseInt(text);
        if (mark < 0 || mark > 100) {
            throw new IllegalArgumentException("Out of range: " + mark);
        }
        return mark;
    }

    public static void main(String[] args) throws InterruptedException {
        countdown(3);

        try {
            openFile("marks.txt");
        } catch (FileNotFoundException e) {
            System.out.println("marks.txt not found, using sample data");
        }

        String[] records = {"85", "abc", "130", "42"};
        int total = 0;
        for (int i = 0; i < records.length; i++) {
            try {
                int mark = parseMark(records[i]);
                total += mark;
                System.out.println("Record " + (i + 1) + ": " + mark);
            } catch (NumberFormatException e) {
                System.out.println("Record " + (i + 1) + ": not a number");
            } catch (IllegalArgumentException e) {
                System.out.println("Record " + (i + 1) + ": " + e.getMessage());
            } finally {
                System.out.println("Processed record " + (i + 1));
            }
        }
        System.out.println("Total of valid marks: " + total);
    }
}

Key moments: record 2 ("abc") makes parseInt throw NumberFormatException; record 3 ("130") makes our own throw fire; and finally prints Processed record N every time, valid or not. The total is 85 + 42 = 127.
